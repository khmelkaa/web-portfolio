# Fyzio Vltava — Multi-Page Clinic Demo Website

## Concept
A calm, medical-modern 5-page website concept for a fictional physiotherapy & sports rehabilitation clinic in Smíchov, Prague (Nádražní 25).

## Pages & Features
- `index.html` — Hero, trust signals, benefits, featured therapies, 4-step process, payment/insurance overview, patient testimonials, FAQ accordion
- `sluzby.html` — Detailed service cards with anchor navigation and direct booking links (`?sluzba=...`)
- `cenik.html` — Pricing table, 5- and 10-session packages, and an interactive treatment price calculator with automatic package discounts
- `tym.html` — 4 licensed physiotherapist profiles with custom portraits, specializations, and languages
- `kontakt.html` — Booking request form (URL-prefilled service, day checkboxes, GDPR consent validation, Netlify Forms ready), transit/parking details, and embedded Google Maps
- Shared stylesheet (`assets/css/styles.css`) & JS (`assets/js/main.js`) with cross-page CZ/EN toggle (`localStorage`)

## Tech Stack
- Plain static HTML5, CSS3, vanilla JavaScript (no build step).

## Client-Facing Description (for Portfolio)
Fyzio Vltava is a 5-page bilingual (CZ/EN) clinic website concept tailored for healthcare and wellness practices. Built with an airy medical-modern layout, it pairs clear service pages and clinician profiles with an interactive package price calculator and GDPR-compliant appointment request flow.
