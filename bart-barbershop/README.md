# Bart & Co. Barbershop — Demo Website

## Concept
A bold, dark-luxury website concept for a fictional newly opened men's barbershop and grooming studio in Karlín, Prague (Sokolovská 88), featuring a complete front-end online booking flow.

## Features
- Full Czech / English toggle (`localStorage` persisted)
- Live Prague opening status indicator in the hero
- Clean service & price cards with direct quick-book triggers
- 3 barber profiles with specialties and direct booking links
- Interactive 4-step online booking widget: service -> barber (or "Anyone") -> 14-day calendar (Sundays closed) & deterministic time slots -> contact validation -> instant confirmation
- Persistent "Your bookings" panel backed by `localStorage` with one-click cancellation (which frees the slot immediately)
- Work gallery with `<dialog>` lightbox, gift vouchers, Google reviews, FAQ accordion, and embedded map

## Tech Stack
- Static HTML5, modern CSS3, vanilla JavaScript (zero dependencies, Netlify Forms ready).

## Client-Facing Description (for Portfolio)
Bart & Co. is a bilingual (CZ/EN) barbershop website concept built for local grooming studios that want to turn Google Maps visitors into booked chairs. It features a dark editorial aesthetic and a working 4-step online booking wizard with calendar availability, barber selection, and booking management.
